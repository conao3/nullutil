Null-safe utilities for Python. Provides concise operators for null coalescing and optional chaining, inspired by modern language features like TypeScript's =??= and =?.= operators.

* Features

- *Null Coalescing*: Provide default values when encountering =None=
- *Safe Member Access*: Access object attributes and call methods without =None= checks
- *Safe Index Access*: Access collection elements without worrying about =None= collections
- *Safe Evaluation*: Execute expressions only when all parameters are non-None

* Usage

** Null Coalescing (qq)

The =qq= function implements the null coalescing pattern (equivalent to =??= in other languages):

#+begin_src python
from nullutil import qq

# Returns lhs if not None, otherwise returns rhs
value = qq(potentially_none_value, "default")

# Practical example
username = qq(user.get("name"), "Anonymous")
#+end_src

** Safe Access (q_)

The =q_= function provides safe attribute access and method calls (equivalent to =?.= in other languages):

#+begin_src python
from nullutil import q_

# Safe attribute access: instance?.member
name = q_(user, "name")  # Returns None if user is None

# Safe method call: instance?.method(args)
result = q_(service, "fetch", ["arg1", "arg2"])  # Positional args as list
result = q_(service, "fetch", {"key": "value"})  # Keyword args as dict
result = q_(service, "process", single_arg)      # Single argument
#+end_src

** Safe Index Access (qL7)

The =qL7= function provides safe index/key access for collections:

#+begin_src python
from nullutil import qL7

# Safe index access: collection?[index]
first_item = qL7(items, 0)      # Returns None if items is None
user_name = qL7(user_dict, "name")  # Works with dictionaries too
#+end_src

** Safe Evaluation (q_let)

The =q_let= function executes an expression only when all parameters are non-None:

#+begin_src python
from nullutil import q_let

# Only executes if all params are non-None
result = q_let([a, b, c], lambda x, y, z: x + y + z)

# With keyword arguments
result = q_let({"x": a, "y": b}, lambda x, y: x * y)

# With single parameter
result = q_let(value, lambda v: v.upper())
#+end_src
